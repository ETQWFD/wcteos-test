.wct 编译手册

下面命令在 Linux 上实测通过，可直接复制。产物能被内核 run 或文件管理器双击执行。

文件结构

层内容作用
代码段objcopy 抽出的扁平机器码真正执行的指令
WCT1 头（24 字节）magic/版本/段数/基址/入口偏移/长度/CRC32内核校验与定位入口
WCTX（可选）WCTX + 密钥 + 长度 + XOR 载荷提高反编译门槛

所以它不是裸二进制：有头、有长度、有 CRC；打包后是密文。WCTX 是混淆不是加密，密钥随文件走。

命令

sudo apt-get update
sudo apt-get install -y gcc-mingw-w64-x86-64

x86_64-w64-mingw32-gcc -ffreestanding -fno-stack-protector -fno-builtin \
    -mno-red-zone -O2 -c hello.c -o hello.o
x86_64-w64-mingw32-ld -e wct_main --image-base 0x00400000 -o hello.elf hello.o
x86_64-w64-mingw32-objcopy -O binary hello.elf hello.bin

VMA=$(x86_64-w64-mingw32-objdump -h hello.elf | awk '$2==".text"{print $4; exit}')
SYM=$(x86_64-w64-mingw32-nm hello.elf | awk '/ T wct_main$/{print $1}')
OFF=$((0x$SYM - 0x$VMA))

python3 build-wct.py hello.bin $OFF hello.wct 0x00400000
./wctpack hello.wct hello.p.wct 0xA5C3E71B

入口与 API

typedef struct { void (*puts)(const char*); void (*putu)(unsigned long long);
                 void (*clear)(void); unsigned long long version;
                 const char *kernel_tag; } WCT_API;
int wct_main(WCT_API *api) { api->puts("hello\r\n"); return 0; }

约束

  • 入口名固定 wct_main，签名 int wct_main(WCT_API*)。
  • 只能走 API 表，不能调 UEFI 协议或系统调用。
  • 代码必须位置无关；首选基址被占用时会重定位。
  • 没有堆、浮点、异常处理。
