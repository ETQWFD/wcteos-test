内核运行报告

测试环境：QEMU 6.2，TCG 纯软件模拟，无 KVM，384MB，单核，OVMF 固件，e1000 网卡。

阶段结果

e100052:54:00:12:34:56，DHCP 取得 10.0.2.15，ARP 网关成功
.wct 模块WCT1 与 WCTX 打包版均加载并返回 0

内存拷贝与填充（rdtsc 原始计数）

copy=3,958,994 cyc/MB   fill=648,771 cyc/MB

同一镜像另一次运行：copy=10,495,550 / fill=7,267,399 cyc/MB，差异 3 倍以上，来源是宿主调度与 TCG 翻译，不是内核本身。

结论

  • TCG 下不能换算主频，也不能算 MB/s，因此本报告不做"比别的系统快"的结论。
  • 能确认的是功能正确：图形、鼠标、网络、模块加载、文件操作都在无头环境实测通过。
  • 要比较速度，必须在同一台真机上用相同镜像与相同测试程序对比。
