# wcteos 终端使用手册

wcteos 的命令提示符是自己实现的（`kernel.c` 的 `process_command`），不依赖 Linux/Windows 的 shell，语法接近 Windows CMD，但只有下面列出的这套命令。

## 提示符

```
tty1 C:\>            ← 开机原生命令行（文本模式）
tty2 C:>             ← 桌面里“终端”窗口内的提示符
```

`C:` 是当前目录（FAT32 卷根）。分卷用 `fs0:` / `fs1:` 前缀可跨盘访问。

## 文件与目录

| 命令 | 说明 |
|---|---|
| `ls` | 列出当前目录内容（目录带 `/`） |
| `cd <路径>` | 切换目录，`cd ..` 返回上级，`cd C:` 回根 |
| `pwd` | 显示当前目录 |
| `cat <文件>` | 显示文本文件内容 |
| `write <文件> <内容>` | 覆盖写入文本 |
| `cp <源> <目标>` | 复制文件 |
| `rm <文件>` | 删除文件 |
| `mkdir <目录>` | 新建目录 |
| `touch <文件>` | 新建空文件 |
| `new <文件>` | 新建并打开编辑 |
| `edit <文件>` | 在文本编辑器里打开 |
| `create <文件>` | 新建文本文件 |

## 程序与脚本

| 命令 | 说明 |
|---|---|
| `run <文件.wct>` | 运行 .wct 可执行程序 |
| `script <文件.wet>` | 执行 .wet 一键脚本 |
| `pkg <文件.dwc>` | 加载 .dwc 依赖声明 |
| `api` | 列出内核可调用接口（.wct 用） |
| `usb` | 列出已枚举的 USB 控制器/设备 |
| `linux` | 显示“不使用 Linux 内核”的说明 |
| `native` | 显示当前运行模式（原生 UEFI） |

## 系统

| 命令 | 说明 |
|---|---|
| `help` | 命令列表 |
| `ver` | 版本号 |
| `about` | 系统名称、构建时间、架构 |
| `sysinfo` | CPU、内存、固件、分辨率 |
| `hw` | PCI 设备清单 |
| `mem` | 内存占用 |
| `date` | 当前日期时间（UEFI GetTime） |
| `ps` | 进程表（PID / 名称 / 状态 / ticks） |
| `pid` | 当前进程 PID |
| `kill <PID>` | 结束进程，PID 1（wct-kernel）不可杀 |
| `sudo <命令>` | 以管理员身份执行 |
| `log` | 查看操作日志 |
| `reboot` | 重启 |
| `poweroff` | 关机 |

## 显示与界面

| 命令 | 说明 |
|---|---|
| `gui` | 进入图形桌面 |
| `exitgui` | 退出桌面回到命令行 |
| `clear` | 清屏 |
| `banner` | 重画启动横幅 |
| `theme <名字>` | 切换配色（ice / paper / blue / dark / brown 等） |
| `color <前景> <背景>` | 指定颜色 |
| `font` | 切换 8x16 / 8x8 字体 |

## 桌面里“运行框”支持的命令

按 F12（或任务管理器“新建进程”）打开运行框，输入：

| 输入 | 结果 |
|---|---|
| `wtr` | 打开终端窗口 |
| `wtcer` | 打开系统属性（名称、版本、安装时间） |
| `tisal` / `taskmgr` | 打开任务管理器 |
| `cfg` | 打开设置（主题、壁纸、网卡状态） |
| `explorer` / `files` | 打开文件管理器 |
| `notepad` / `edit` | 打开文本编辑器 |

勾选“以管理员身份运行”后，进程以管理员标记启动（任务管理器里状态显示为 admin）。

## 例子

```
C:> cd \wct
C:\wct> ls
C:\wct> run hello.wct
C:\wct> ps
C:\wct> kill 5
C:\wct> date
```

## 限制

- 没有管道、通配符、命令替换，也不支持 `&&` / `|`
- 路径分隔符用 `\`，大小写不敏感
- 只挂载 FAT32；NTFS/ext4 不识别
