终端使用手册

终端是 wcteos 内核里自己实现的命令解释器，所有命令都走内核 API，不调用 Linux、不依赖任何外部程序。窗口正文是深色背景，提示符固定显示 tty2>，并且像 Linux 那样紧跟最后一行输出，不会钉在窗口底部。

一、怎么打开

  • 桌面双击「终端」图标；
  • 任务栏「开始」菜单里点「终端」；
  • 任何界面按 F1 打开开始菜单，再选终端；
  • 运行框输入 wtr 回车。

二、输入与快捷键

操作行为
直接打字输入到当前命令行，仅接受可见 ASCII
Enter执行当前命令并回显输出
Backspace删掉一个字符
↑ / PageUp向上滚动历史输出
↓ / PageDown向下滚动
Esc关闭终端窗口

三、文件类命令

命令作用示例
ls [路径]列目录，省略参数就是当前目录ls \wct
cd [目录]切换目录，cd .. 回上级cd \wct\wall
pwd显示当前目录pwd
cat 文件 / type显示文本内容cat \wct\note.txt
new 文件 / touch新建空文件new \wct\a.txt
write 文件 文本创建或覆盖并写入一行文本write \wct\a.txt hello
edit 文件用图形文本编辑器打开，文件不存在会创建edit \wct\a.txt
mkdir 目录 / md建目录mkdir \wct\test
rm 文件 / del删除文件del \wct\a.txt
rd 目录删除空目录（rm 的别名）rd \wct\test
cp 源 目标复制文件cp \wct\a.txt \wct\b.txt
ren 源 新名 / rename重命名，可只改后缀；实现是复制后删源ren \wct\A.WCT \wct\B.WCT
attrib 文件名称、字节数、目录/只读/隐藏/系统属性位attrib \wct\HELLO.WCT
run 文件.wct执行模块，支持 WCT1 与 WCTX 打包版run \wct\HELLO.WCT
script 文件逐行执行 .wet 脚本script \wct\boot.wet

受保护路径：\EFI 下的引导文件、.dwc 依赖声明、.glf 壁纸。无论用 rm 还是文件管理器删除都会被拒，这是设计如此，不是权限 bug。

四、网络类命令

命令作用输出示例
ipconfig驱动名 + IP + 网关 + dhcp/arp/link 状态e1000 ip=10.0.2.15 gw=10.0.2.2 dhcp=ok arp=ok link=up
netstat同 ipconfig，并附收发帧计数rx=3 tx=3
route打印当前网络配置（这版没有路由表）e1000 ip=... link=up
ping对网关发 4 个 ICMP echo，报应答数和最小往返 TSC 周期网关应答 4/4 次

这版没有 DNS、没有路由表，ping 只能打网关；TCG 模拟环境下的周期数随宿主调度波动，只作功能验证，不代表真实网络时延。

六、脚本与自动执行

.wet 相当于批处理：每行一条命令，script 文件 会逐行执行。内核启动时如果存在 \wct\autorun，也会逐行执行里面的命令，用于无人值守测试。

ipconfig
attrib \wct\HELLO.WCT
run \wct\HELLO.WCT

七、当前限制

  • 没有管道、重定向、通配符、Tab 补全、命令历史。
  • 没有 DNS、没有路由表，ping 仅网关。
  • 没有真正的权限模型；“管理员”只是运行框里的标记，不改变文件访问权。
  • 不能执行 Linux 程序，也没有 Linux 兼容层。
