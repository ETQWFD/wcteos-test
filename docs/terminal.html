终端使用手册

wcteos 的终端是内核自己实现的命令解释器，所有命令走内核 API，不调用 Linux，也不依赖外部程序。窗口正文是深色背景，提示符 tty2> 紧跟最后一行输出，不会钉在窗口底部。

一、打开方式

  • 桌面双击「终端」图标
  • 开始菜单选「终端」
  • 任意界面按 F1 打开开始菜单
  • 运行框输入 wtr 回车

二、输入与快捷键

操作行为
直接打字输入到当前命令行，只接受可见 ASCII
Enter执行并回显
Backspace删一个字符
↑ / PageUp向上滚动
↓ / PageDown向下滚动
Esc关闭终端窗口

三、文件命令

命令作用示例
ls [路径]列目录ls \wct
cd [目录]切换目录cd \wct\wall
pwd显示当前目录pwd
cat / type显示文本cat \wct\note.txt
new / touch新建空文件new \wct\a.txt
write 文件 文本覆盖写入一行write \wct\a.txt hello
edit 文件图形编辑器打开edit \wct\a.txt
mkdir / md建目录mkdir \wct\test
rm / del删文件del \wct\a.txt
rd删空目录rd \wct\test
cp 源 目标复制cp \wct\a.txt \wct\b.txt
ren 源 新名 / rename重命名，可只改后缀ren \wct\A.WCT \wct\B.WCT
attrib 文件名称、字节数、属性位attrib \wct\HELLO.WCT
run 文件.wct执行模块，支持 WCTXrun \wct\HELLO.WCT
script 文件逐行执行 .wetscript \wct\boot.wet

受保护路径：\EFI 下的引导文件、.dwc 依赖声明、.glf 壁纸。删除会被拒，这是设计，不是 bug。

tty2> attrib \wct\HELLO.WCT
  名称：HELLO.WCT
  大小：16440 字节
  属性：文件

四、网络命令

命令作用
ipconfig驱动、IP、网关、dhcp/arp/link
netstat同 ipconfig，并附 rx/tx 计数
route打印当前网络配置（无路由表）
ping对网关发 4 个 ICMP echo
tty2> ipconfig
e1000 ip=10.0.2.15 gw=10.0.2.2 dhcp=ok arp=ok link=up
rx=3 tx=3

没有 DNS、没有路由表，ping 只能打网关；TCG 下的周期数受宿主调度影响，只作功能验证。

六、脚本与自动执行

.wet 相当于批处理，每行一条命令。启动时若存在 \wct\autorun，内核会逐行执行，常用于无人值守测试。

ipconfig
attrib \wct\HELLO.WCT
run \wct\HELLO.WCT

七、限制

  • 无管道、重定向、通配符、Tab 补全、命令历史
  • 无 DNS、无路由表，ping 仅网关
  • 没有真正的权限模型，“管理员”只是运行框里的标记
  • 不能执行 Linux 程序，也没有 Linux 兼容层
