终端使用手册

终端是内核内自研的命令解释器，命令自己实现，不调用 Linux。提示符 tty2> 紧跟输出，不钉在窗口底部。

文件

命令说明
ls / dir列当前目录
cd PATH切换目录
cat / type FILE显示文件内容
mkdir / md DIR建目录
rm / del FILE删除；系统文件会拒绝
cp A B复制
ren A B重命名，可只改后缀（复制后删源）
attrib FILE名称/字节数/目录/只读/隐藏/系统位
run FILE.wct执行模块，支持 WCTX 打包版

网络

命令说明
ipconfig / netstat驱动、ip、网关、dhcp/arp/link、rx/tx
route当前网络配置（无路由表）
ping对网关发 4 个 ICMP echo，报应答数与最小 TSC 周期

系统

命令说明
ps / taskmgr进程表与任务管理器
sysinfo / wtcer系统属性
date / time固件时间
clear清屏
help命令总表

限制

  • 没有管道、通配符、Tab 补全、命令历史。
  • 没有 DNS 与路由表，ping 只打网关。
  • 没有权限模型，但文件管理器与 rm 都会拒删 \EFI 与 .dwc/.glf 系统文件。
