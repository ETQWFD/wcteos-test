# .wcte 格式规范 v2

容器（little-endian）：

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 4 | magic `WCTE` |
| 4 | 1 | version = 2 |
| 5 | 1 | flags（bit0=1 整体存储） |
| 6 | 1 | block_log2（14..20，默认 18 = 256 KB） |
| 7 | 1 | 保留 = 0 |
| 8 | 8 | original_size (u64) |
| 16 | 4 | block_count (u32) |
| 20 | 16×block_count | 块索引：orig_len u32, comp_len u32, hash u64 |

块数据紧随索引之后，按块顺序排列。`comp_len == orig_len` 表示该块为**存储块**（原始字节直接拷贝）。

单块负载（字节流指令，输出达到 orig_len 即结束）：

- `0x00..0x7F`：字面量，长度 = 值 + 1（1..128），随后跟该长度的原始字节
- `0x80..0xFF`：匹配，长度 = (值 & 0x7F) + 3（3..130），随后 2 字节偏移（1..65535）

长字面量/长匹配按 128/130 拆成多条指令；实现简单到不可能解析错。

完整性与安全性：
- 每块 64 位哈希（8 字节并行混合），解压后逐块校验，任何损坏立刻返回失败，不会产出半成品
- 块独立：可并行压缩、可随机解压定位、单块损坏不影响其它块
- 解码全部是 memcpy + 短拷贝展开，无查表分支
